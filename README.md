# Lumen

Лёгкая замена Yeelight Station для **Yeelight Screen Light Bar Pro** (и других ламп Yeelight с LAN Control).
C# / WPF, без сторонних библиотек, серая тёмная тема, живёт в трее.

## Что умеет

- **Поиск ламп** в сети + добавление по IP. Поиск идёт с каждого сетевого адаптера отдельно, поэтому VMware/VPN-адаптеры ему не мешают.
- **Основной свет**: вкл/выкл, яркость, цветовая температура 2700–6500 K, пресеты.
- **Задняя подсветка**: цвет (оттенок + насыщенность + палитра), яркость.
- **Эффекты**: дыхание, радуга, пульс, свеча, закат, океан, неон, строб, со скоростью. Их крутит сама лампа, так что они работают и при закрытом Lumen.
- **Синхронизация с экраном**: подсветка повторяет доминирующий цвет картинки, до 30 кадров/с. На Screen Light Bar Pro можно включить **две зоны**: левая и правая половины подсветки повторяют свои половины экрана (кнопка «Проверить зоны» и «Поменять местами», если лампа считает левой другую сторону). Если мониторов несколько, можно выбрать нужный.
  - Чёрные полосы фильмов и панель задач в расчёт цвета не идут.
  - Поддерживается HDR (кадр FP16 приводится к обычной шкале по «Яркости SDR-содержимого» Windows).
  - При блокировке экрана и сне синхронизация ставится на паузу, после — продолжается. Если Lumen закрыть во время синхронизации, при следующем запуске она продолжится сама.
- **Слайдеры подсветки** на Screen Light Bar Pro работают по UDP — без лимита лампы 60 команд в минуту, мгновенно.
- **Журнал** `%AppData%\Lumen\lumen.log` (кнопка «Открыть журнал»): что ушло в лампу, что она ответила и прислала сама, подключения, блокировка и сон.
- **Трей**: клик по иконке — мини-панель (свет, подсветка, синхронизация, яркость, температура, цвет), двойной клик — окно, правый — меню. Автозапуск с Windows, одна копия приложения.
- Состояние синхронизируется в обе стороны: если переключить свет пультом, UI обновится.

## Установка

Скачай со страницы **Releases** один из файлов. .NET ставить не нужно, всё уже внутри.

- **`Lumen-<версия>-setup.exe`** — установщик. Ставит Lumen для текущего пользователя в `%LocalAppData%\Programs\Lumen` без прав администратора, добавляет ярлык в «Пуск» и по желанию автозапуск. Новая версия ставится поверх старой: установщик сам закроет запущенный Lumen, настройки сохранятся.
- **`Lumen-<версия>-portable.exe`** — один файл без установки, можно запускать хоть с флешки. Первый запуск чуть дольше: Windows распаковывает библиотеки WPF во временную папку.

Нужна 64-битная Windows 10 или 11. Файлы не подписаны сертификатом, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае». Контрольные суммы лежат рядом, в `SHA256SUMS.txt`.

Удаление: «Параметры» → «Приложения» → Lumen. Деинсталлятор уберёт автозапуск и спросит, удалять ли настройки.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0), для установщика ещё [Inno Setup 6](https://jrsoftware.org/isdl.php) (`winget install JRSoftware.InnoSetup`).

```
build.cmd
```

Или из PowerShell: `.\build.ps1` (версия берётся из `Lumen.App.csproj`), `.\build.ps1 -Version 1.2.0`, `.\build.ps1 -NoInstaller` (только переносная версия, Inno Setup не нужен). Результат — в `dist\`: переносной exe, установщик и `SHA256SUMS.txt`.

Тесты: ядро (протокол на поддельной лампе, математика цвета, троттлинг, расписание) и модель приложения (подключение, включение подсветки, лимит команд, переименование, расписание — тоже на поддельной лампе):

```
dotnet test
```

Через Rider или Visual Studio: открыть `Lumen.sln` и запустить проект `Lumen.App`.

## Первый запуск

1. На лампе должен быть включён **LAN Control** (порт 55443).
2. Нажми **«Найти»** или **«＋ по IP»** → `192.168.10.250`.
3. Screen Light Bar Pro синхронизируется по UDP, брандмауэр не нужен. Обычные лампы используют music mode: лампа сама подключается к ПК, поэтому Windows может спросить доступ в брандмауэре — разреши его для той сети, где стоит лампа.

Настройки хранятся в `%AppData%\Lumen\settings.json`.

## Ограничения

- Экран захватывается через DXGI Desktop Duplication (обычный кадр BGRA8 или HDR FP16). Если она недоступна (удалённый рабочий стол, экран блокировки), Lumen переключается на GDI — он медленнее (на 4K ~15 кадров/с) и в эксклюзивном полноэкранном режиме даёт чёрный кадр.
- У lamp15 (прошивка 38) баг: если подсветку выключили в режиме HSV, `bg_set_power on` отвечает `ok`, но не включает её. Поэтому Lumen задаёт цвет через `bg_set_rgb`, а включает подсветку через `bg_set_scene`.
- Не запускай синхронизацию одновременно с Yeelight Station: у лампы ограниченное число UDP-сессий (до 4) и одно music-соединение.
- В режиме двух зон яркость постоянная: после команды `set_segment_rgb` лампа около секунды игнорирует `bg_set_bright`.
- Основной свет (и подсветка ламп без UDP-сессии) управляется по TCP с лимитом лампы ~60 команд в минуту. Если лимит исчерпан, Lumen покажет это в статусе и дошлёт последнее значение, когда лампа «остынет».
- Лампа держит лишь несколько TCP-соединений и сбрасывает лишние — не держи одновременно открытыми Lumen, Yeelight Station и приложение Yeelight.
- Razer Chroma в Lumen нет. Для синхронизации с играми через Chroma по-прежнему нужна Station.

### Протокол Yeelight

Каждая команда — одна строка JSON, завершённая `\r\n`:

```json
{"id":1,"method":"bg_set_hsv","params":[220,100,"smooth",250]}
```

| Что | Метод |
|---|---|
| Основной свет вкл/выкл | `set_power ["on","smooth",300]` |
| Яркость | `set_bright [1..100,"smooth",200]` |
| Температура | `set_ct_abx [2700..6500,"smooth",200]` |
| Подсветка вкл/выкл | `bg_set_power` |
| Цвет подсветки | `bg_set_hsv [hue,sat,...]` / `bg_set_rgb [R*65536+G*256+B,...]` |
| Эффект | `bg_start_cf [0,1,"duration,1,rgb,bright,..."]` |
| Music mode | `set_music [1,"ip_пк",port]` |
| Две зоны подсветки | `set_segment_rgb [левый_rgb, правый_rgb]` |

### UDP-сессия (Screen Light Bar Pro)

У lamp15 нет `set_music`, зато в `support` есть `udp_sess_new`. Протокол (UDP, порт 55444):

1. `{"id":1,"method":"udp_sess_new","params":[]}` → `{"id":1,"method":"udp_sess_token","params":{"token":"…"}}`
2. Каждая команда — датаграмма с токеном: `{"id":2,"method":"bg_set_rgb","params":[…],"token":"…"}`. Ответов нет.
3. Раз в несколько секунд — `udp_sess_keep_alive ["keeplive_interval","10"]` (лампа отвечает `["ok"]`). Без него сессия истекает.
